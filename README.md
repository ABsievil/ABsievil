## About Me

Hello! I'm **Cuong Nguyen Cao** (aka **ABsievil**), a Backend Developer with over 1 year of professional experience building and maintaining production backend services with **NestJS**. I'm finishing my Bachelor's degree in Computer Science at [VNU-HCMUT](https://hcmut.edu.vn/) (graduating 11/2026).

At work, I develop services for the **ALOBO ecosystem**, a multi-product platform for sports-facility booking and management, and I led the migration of its Chat AI assistant from intent-based NLP to a **RAG pipeline**. Outside of work, I build my own products, such as **OmniChat**, a multi-tenant Zalo chatbot platform.

I love building efficient, scalable and secure backend systems, and I'm looking to keep growing in a team that cares about maintainable architecture.

## Featured Projects

### [OmniChat: Multi-tenant Zalo Chatbot Platform](https://github.com/ABsievil/ncg-omnichat-be) (03/2026 – 09/2026)
Backend platform that connects multiple shops to Zalo via QR login and auto-replies to customers with an AI chatbot. Built solo, end to end.
- Secure REST APIs (JWT, OTP, RBAC) with tenant isolation
- A worker that listens for Zalo messages, plus a **RAG agent** that retrieves shop knowledge before answering
- **Tech Stack**: NestJS, MongoDB, Redis, LangChain, OpenAI, Milvus/Zilliz, Google Cloud Pub/Sub, S3/R2, Docker
- **GitHub**: [ncg-omnichat-be](https://github.com/ABsievil/ncg-omnichat-be)

### [Examify System](https://examify-online.azurewebsites.net/) (03/2025 – 04/2025)
An online examination platform built with **Spring Boot** and **ReactJs** during the Scrum course by Axon Active. Teachers create tests with unique passcodes and view class analytics, while students take exams and review results.
- Built the backend RESTful APIs with Spring Security (JWT, OAuth2 login via Google/GitHub), Spring Data JPA and Spring Mail; containerized with Docker and deployed on Azure
- **Tech Stack**: Spring Boot, PostgreSQL, ReactJs, Docker, Azure
- **GitHub**: [BE_Examify-System](https://github.com/ABsievil/BE_Examify-System) · **Website**: [examify-online.azurewebsites.net](https://examify-online.azurewebsites.net/)

### [Student Smart Printing Service (SSPS)](https://hcmut-ssps.azurewebsites.net) (09/2024 – 01/2025)
A web app for HCMUT students to upload documents, set print options, buy print credits via VNPay/QR, and track history; admins manage printers and view analytics.
- **Tech Stack**: Spring Boot, PostgreSQL, ReactJs, VNPay, Docker, Azure
- **GitHub**: [HCMUT_SSPS](https://github.com/ABsievil/HCMUT_SSPS) · **Website**: [hcmut-ssps.azurewebsites.net](https://hcmut-ssps.azurewebsites.net)
